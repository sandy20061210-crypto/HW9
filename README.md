## 問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

在測試一中，桌遊整理後的串列是 `["amy", "ben", "amy", "cora"]`，雖然有 4 筆資料，但 `"amy"` 出現兩次其實是同一位參加者。依活動規則，同一人在同一場活動重複報名只算一位參加者、收一次費用，所以實際參加人數是 3 人（`amy`、`ben`、`cora`）。

直接把字串拆成 `list`，**保留了**原始的出現順序與重複報名紀錄，但**沒有自動去重**；轉成 `set` 後，**保留了**不重複的參加者名單且方便做集合運算，但**失去了**原本的先後順序與重複次數資訊。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

在測試三中，桌遊集合與電影集合都是 `{"amy", "ben", "cora"}`，兩者完全相同，所以聯集（全部參加者）只有 3 人（`len(board_set | movie_set) = 3`），也就是「總不重複人數」為 3 人。

但因為這 3 人兩場活動都參加，兩場各自去重後各有 3 人，所以「報名人次」是兩場去重人數相加：`3 + 3 = 6` 人次。收費是依各場去重人數分開計算：`3 × 120 + 3 × 80 = 360 + 240 = 600` 元，因此總應收仍是 600 元。
